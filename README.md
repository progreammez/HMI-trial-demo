# EV HMI Dashboard (Qt/QML + C++)

Production-inspired EV dashboard HMI built using Qt Quick/QML and C++ for Raspberry Pi 5 embedded systems.

## Features
- Modular Qt/QML architecture
- C++ telemetry backend
- Simulated EV telemetry
- Drive modes (Eco/City/Sport)
- Diagnostics dashboard
- Embedded-focused UI design
- Touchscreen-ready layout system

## Stack
- Qt 6
- QML / Qt Quick
- C++
- CMake
- Raspberry Pi 5 target

## Architecture
- QML frontend
- C++ backend
- QObject + Q_PROPERTY
- Modular component system

## Planned Integrations
- STM32 telemetry
- Spotify API
- Weather API
- Maps/navigation

## Status
Currently in active development.
